    Notes

    Where the numbers on this page come from.

    Measured, not typed

    Bounding box, volume, plan outline and hole size in assets/model.json come from reading the STEP file with build123d and shapely (tools/inspect_cad.py).

    How it is built

    A 3 mm flat base carries a 1.5 mm raised relief of rings, an octagon and a cross, then the key hole is cut through the lug. generate_keyring.py writes the STEP and STL. The script defines these shapes in code and does not read the SVG, which is shipped alongside as the 2D artwork.

    Plan accuracy

    Curves in the plan view are drawn as many short straight segments, so the drawing is an approximation of the true arcs. The size and volume figures come from the exact STEP solid.

    Open it locally

    This page loads JSON and ES modules, so serve the folder (for example python3 -m http.server) instead of opening the file directly.
